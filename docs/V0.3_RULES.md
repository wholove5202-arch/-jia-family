# V0.3 新增正式规则

## 年度成长头像
- 每年可从本人公开个人相册/有权限的家庭相册中推荐当年新头像。
- 绝不自动更换，必须本人明确确认。
- 历年头像保留历史。
- 未认领人物不自动换头像。
- 私密空间照片不得参与推荐。

## 身故确认
- 单个人无权直接把家庭成员改为身故。
- 由一人发起，至少另外 2 名符合资格的成年家庭成员独立确认。
- 发起人不算第二确认人。
- 任一有效异议出现后进入 disputed，不自动切换纪念状态。
- 保留发起、确认、异议和完成时间记录。
- 身故确认只确认事实，不授予任何账号或私密数据访问权。

## 身后传承
- 只能由本人在生前设置。
- 本人可决定是否开启。
- 可逐项指定内容，而不是整个私密空间一键公开。
- 可指定一个或多个具体传承人。
- 可设置身故确认后开放或指定日期后开放。
- 未明确授权的内容永久保持私密。
- 家主、确认人、管理员不得扩大本人授权。
- 多人身故确认仅作为触发本人预设规则的条件。
- 私密内容在释放前始终禁止进入 AI 管线；释放后也不默认授权 AI。
