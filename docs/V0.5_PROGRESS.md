# V0.5 第一阶段正式开发

本轮已写入：
- 公共家庭数据与私密空间数据使用不同 AsyncStorage namespace。
- 多家庭本地 store：families / activeFamilyId。
- 父母关系编辑、配偶双向关系、兄弟姐妹推导和基础冲突检测。
- 年度成长头像：只从非私密、包含本人的当年照片候选；本人确认才写入头像历史。
- 身故确认：1 人发起 + 另外至少 2 名符合资格成年家庭成员独立确认。
- 异议立即进入 disputed，不自动纪念化。
- 完整确认审计轨迹。
- 身后传承：只释放本人预先授权给当前查看者的具体内容。
- 身故确认与传承权限完全分离。

下一轮 UI 接线重点：
1. 多家庭创建/切换页面接入 phase1Store。
2. 关系编辑器接入 relationshipRules。
3. 家族树由父母/配偶关系动态绘制。
4. 年度头像确认弹窗。
5. 身故确认进度页、异议页。
6. 身后传承设置页面。
