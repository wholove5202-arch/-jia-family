# V1.9 真机运行准备

本轮重点不是增加展示功能，而是减少首次 Expo/iOS/Android 运行的不确定性。

- 删除当前未使用的 `expo-file-system` 依赖，降低依赖安装面。
- `expo-image-picker` 权限改由官方 Expo config plugin 管理，iOS/Android 使用明确中文权限文案。
- Android 不再手工硬编码 Android 13 媒体读取权限；选择器自身负责系统选择/授权流程，保留 CAMERA 给后续拍摄/扫描入口。
- 新增 `scripts/static-check.js`，检查所有本地相对 import 是否存在。
- 新增 `npm run check:project`，在有网络/依赖环境时串联静态检查与 `expo-doctor`。

## 本环境实际检查结果
- Node 22 / npm 10 可用。
- 本地相对 import 检查可运行。
- `npm install` / `npx expo-doctor` 因当前执行环境网络安装阶段超时，不能据此声称 Expo 运行时已经通过。
- 因无 Xcode/Apple 签名环境，本轮仍未生成 IPA。

## 下一步
在可联网的 Node/Expo 环境执行 `npm install` → `npx expo-doctor` → `npx expo start`，随后进入 EAS iOS/Android preview build。
