# V1.6 iOS + Android 双端固定验收要求

## 共用功能
- 同一 React Native 业务代码支持 iOS / Android。
- 家庭、成员、相册、家庭群、家庭记事、人物档案、纪念、私密空间逻辑保持一致。
- 后续云端账号和家庭数据必须跨 iPhone / Android 同步，禁止平台私有数据模型。

## iOS
- 照片/视频选择权限。
- 相机/老照片扫描权限。
- 底部安全区域、刘海/灵动岛布局。
- EAS preview / App Store 构建。

## Android
- Android 13+ READ_MEDIA_IMAGES / READ_MEDIA_VIDEO。
- CAMERA 权限。
- 系统实体/手势返回键：子页面返回，首页再退出。
- 全面屏底部区域。
- EAS preview APK/AAB 构建。
- 后续重点真机覆盖：华为、小米、OPPO、vivo、荣耀及主流 Android 版本。

## 中国大陆正式版
- 不依赖 Google Play Services 才能完成核心功能。
- 推送、地图、短信、云存储、AI 等后续服务必须采用中国大陆可用方案或 provider abstraction。
