# 第一阶段真机冒烟测试清单

启动与保存
- 启动显示数据恢复状态。
- 创建/切换家庭后退出 App，再打开应恢复当前家庭。
- 家庭 A 与家庭 B 的照片、群聊、家庭记事互不串数据。

家庭相册
- ＋ → 手动上传照片/视频 → 当前家庭相册出现。
- 点击照片 → 手动确认人物 → 保存。
- 人物标记后，该照片才可进入对应人物的年度头像候选。

年度头像
- 仅本人、当年、非私密、已标记人物照片可作为候选。
- 本人确认后写入 avatarHistory。
- 人物档案显示最近已确认年度。

家庭群
- 文字消息可发送并持久保存。
- ＋选择照片/视频作为群消息。
- 群媒体默认 pending_owner_decision。
- “保存到家庭相册”后 albumArchived=true；“不用保存”则 false。

私密空间
- 个人记事本 / 想念TA / 身后传承全部保存到 PRIVATE namespace。
- PRIVATE 固定 aiAllowed=false。
- 家庭切换不得改变或泄露个人 PRIVATE 数据。
- 未授权内容不得因身故确认而公开。

身故确认
- 发起者不算确认人。
- 至少 2 位其他符合条件的成年家庭成员确认。
- 有有效异议则 disputed，不能切换纪念状态。
- confirmed 后只改变人物纪念状态，不授予账号或私密数据访问权。
