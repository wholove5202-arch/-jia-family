# V0.9 — 主 App 整合

本轮关键变化：
- 不再只是散落的功能组件：正式 App.js 已切换到 IntegratedPhase1App。
- 首页可进入家族树、相册、家庭群、家庭记事、纪念、私密空间等主模块。
- 家庭名称可进入多家庭管理，创建/切换家庭后回到对应家庭首页。
- 家族树 → 人物档案 → 关系编辑形成完整导航链。
- 本人档案 → 年度成长头像确认入口。
- 其他在世成员档案 → 身故确认入口。
- 私密空间 → 个人记事本 / 想念TA / 身后传承逐项授权形成完整导航链。
- 家庭相册直接使用本地分类索引。
- 原 V0.8 App.js 已保留为 src/LegacyAppV08.js，避免丢失旧实现。
