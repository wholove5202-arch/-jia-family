# V1.5 EAS / iPhone 真机交付准备

## 依赖核对
工程使用 Expo SDK 54 + React Native 0.81.x + React 19.1，属于 Expo SDK 54 对应版本族。
新增 babel.config.js、metro.config.js、eas.json 和标准 build scripts。

## iPhone 内测方案
preview profile 使用 `distribution: internal`。
iOS internal distribution 需要 Apple 签名和已登记测试设备 UDID。
真正生成 IPA 时需要在 EAS/Apple 登录流程中完成凭据授权；这些账号授权不能由源码文件伪造。

## 预期命令
- npm install
- npx expo-doctor
- npx expo start
- eas device:create
- eas build --platform ios --profile preview

## 安全
credentials.json / .env / Apple 证书类文件均加入 .gitignore，不应打进源码 ZIP。
